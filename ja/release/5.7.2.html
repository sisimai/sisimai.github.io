{{ site.html.ss }} 5.7.2

2026/08/31

{{ site.html.ss }} 5.7.2をリリースしました。 このバージョンにおける主な変更点はPerl版とRuby版における脆弱性(ReDoS)の修正と Go版のバグ修正です。 Perl版{{ site.html.ss }}で入った変更内容にはPerlが、 Ruby版{{ site.html.ss }}ではRubyが、 Go版{{ site.html.ss }}ではGoが、 それぞれ冒頭に入っています。

{{ site.html.ss }} 5.0.0でVersion 4系とは非互換な変更が多く入っていますので、 インストールまたはアップグレードの前に実行環境のPerlやRubyのバージョンを確認してください。

脆弱性(ReDoS)の修正

  • Perl Ruby Sisimai::Stringクラスのto_plainメソッドに細工したHTMLパートを持つ バウンスメールをと押すと処理時間が大幅に増えCPU使用率が100%に張り付く脆弱性を修正しました。 この脆弱性は{{ site.html.ss }} 5.7.1以前の全てのバージョンに影響します。 正規表現を全く使っていないGo版{{ site.html.ss }}にこの脆弱性はありません。

バグ修正

  • Go バウンスメールに含まれる元メールのMessage-Id:ヘッダーと Subject:ヘッダーの値が小文字に誤変換されるバグを修正しました。 #443 #444 #445

コードの改善と環境

  • Ruby Sisimai::Messageのtidyメソッドがバウンスメール成形する処理で メモリを使いすぎるコードを修正しました。 #455
  • Perl Perl 5.44での実行を確認しました。 #683
  • Go Go 1.27でのビルドを確認しました。 #441
