{{ site.html.ss }} 5.7.1

2026/07/17

{{ site.html.ss }} 5.7.1をリリースしました。 このバージョンにおける主な変更点は再帰処理に対する防御的な制限の追加と小さなバグの修正です。 Perl版{{ site.html.ss }}で入った変更内容にはPerlが、 Ruby版{{ site.html.ss }}ではRubyが、 Go版{{ site.html.ss }}ではGoが、 それぞれ冒頭に入っています。

{{ site.html.ss }} 5.0.0でVersion 4系とは非互換な変更が多く入っていますので、 インストールまたはアップグレードの前に実行環境のPerlやRubyのバージョンを確認してください。

バグ修正

  • Go 読み込むメールボックスの最大サイズ制限値が2TBになっていたのを2GBに修正。 #421
  • Perl Ruby Go SMTPコマンドを検出するためのリストでHELOコマンドが重複していたバグを修正。

攻撃耐性の向上

  • Perl Ruby Go 深くネストしたMIME構造を処理する最大階層を64に制限するようにしました。 #670 #441 #423

コードの改善

  • Perl Ruby コード内で参照するバウンス理由とSMTPコマンドとAction: の値をそれぞれ定数化しました。 #672 #676 #677 #443 #447 #448
