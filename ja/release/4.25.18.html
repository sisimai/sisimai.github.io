リリースノート

{{ site.html.ss }} 4.25.18

2026/08/31

{{ site.html.ss }} 4.25.18をリリースしました。 このバージョンにおける主な変更点はPerl版とRuby版における脆弱性(ReDoS)の修正です。

{{ site.html.ss }} 4系は全体がクラッシュするような致命的バグの修正と 影響の大きなサービスの変更に対応するのみの状態になっていますので、ドメイン認証やレピュテーションなど、 現代の配信エラーに対応した{{ site.html.ss }} 5系へのアップグレードをおすすめします。

{{ site.html.ss }} 5.0.0でVersion 4系とは非互換な変更が多く入っていますので、 インストールまたはアップグレードの前に実行環境のPerlやRubyのバージョンを確認してください。

変更点

  • Perl Ruby Sisimai::Stringクラスのto_plainメソッドに細工したHTMLパートを持つ バウンスメールをと押すと処理時間が大幅に増えCPU使用率が100%に張り付く脆弱性を修正しました。 この脆弱性は{{ site.html.ss }} 4.25.17以前の全てのバージョンに影響します。
